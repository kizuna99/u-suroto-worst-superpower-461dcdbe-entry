A tiny program that writes exactly one line to `/output/entry.txt` — a
superpower so useless it loops back to magnificent: **you can make any
ceiling fan spin exactly 2% slower, but it costs you one full hour of
staring at it.** The line was drafted with an OpenCode free-model round,
then won a criteria-ordered tournament against the judge's published
criteria (genuinely useless, funny to picture in use, unexpected, tight
and specific, clear in one reading), beating the ink-pen diagnosis and
the handshake crouton: it is neither a curse nor secretly useful, and
its two concrete numbers do the whole joke. Output is byte-exact:
87 UTF-8 bytes, no trailing newline. Run it with `python3 main.py`.
